# Phase 4: Composio Actions — Slack + Calendar (Read-First)

## Goal
Give the agent real-world reach. Two key changes from V1:

1. **Calendar is now read-first** — `get_current_and_next_event()` runs at session start and feeds the Observer Agent so it knows exactly what you should be working on. Writing to calendar is only done at end-of-day for genuinely empty slots.

2. **Slack messages are task-specific** — the Intervener Agent crafts messages that reference your actual calendar task and time remaining, not generic nudges.

**Depends on**: Phase 2 (Intervener Agent calls these actions)

## 4.2 New File: `backend/actions/calendar_action.py`

Complete rewrite from V1. Read-first architecture.

### Primary function — runs at session start

```python
def get_current_and_next_event() -> dict:
    """
    Fetch what's on the calendar RIGHT NOW and what's coming next.
    This feeds the Observer Agent — it's how the agent knows
    "user should be writing applyPlan() right now, not watching YouTube."

    Called: at session start + every 30 mins during session.

    Returns:
    {
      "current_event":     "Write applyPlan() + unit tests",
      "start_time":        "9:00 AM",
      "end_time":          "11:00 AM",
      "minutes_remaining": 47,
      "next_event":        "Code review with team",
      "next_start_time":   "11:00 AM",
      "minutes_until":     47
    }
    """
```

### Meeting approach detection — runs every 5 mins

```python
def check_meeting_approaching(threshold_minutes: int = 10) -> dict | None:
    """
    Returns meeting info if one starts within threshold_minutes.

    "Code review starts in 8 mins. Good stopping point?"

    Returns None if no meeting approaching.
    """
```

### End-of-day proactive blocking — runs once at session end

## 4.4 Wire Calendar into Session Start (`backend/main.py`)

At session start, fetch calendar and store in shared context:

```python
if event.event == "session_start":
    from db.logger import log_session_start
    from actions.calendar_action import get_current_and_next_event

    log_session_start(event.timestamp)

    # Fetch calendar — store for Observer Agent to use
    calendar = get_current_and_next_event()
    agent_context["calendar"] = calendar
    agent_context["focus_active"] = True

    if calendar.get("current_event"):
        print(f"[Calendar] Current task: {calendar['current_event']}")
        print(f"[Calendar] Ends in: {calendar.get('minutes_remaining')} mins")

    return AgentResponse(action=ActionType.NONE)
```

## 4.5 Meeting Approach Check (background task)

Add a periodic check for approaching meetings using `asyncio`:

```python
# In main.py lifespan startup:
async def meeting_check_loop():
    """Checks every 5 minutes if a meeting is approaching."""
    while True:
        await asyncio.sleep(300)  # Every 5 mins
        if not agent_context.get("focus_active"):
            continue
        try:
            from actions.calendar_action import check_meeting_approaching
            from actions.slack_action import send_slack_nudge
            meeting = check_meeting_approaching(threshold_minutes=10)
            if meeting:
                msg = (
                    f"{meeting['meeting_name']} starts in "
                    f"{meeting['starts_in_mins']} minutes. "
                    f"Good stopping point?"
                )
                await asyncio.to_thread(send_slack_nudge, msg)
        except Exception as e:
            print(f"[MeetingCheck] {e}")

@asynccontextmanager
async def lifespan(app: FastAPI):
    asyncio.create_task(meeting_check_loop())
    yield
```

## 4.6 How Calendar Changes the Agent Behavior

**Before (V1)**: Observer inferred task from tabs/apps alone.
```
Tab: "planner.py — VS Code"
Observer: "Probably writing Python code" (confidence 0.78)
```

**After (V2)**: Observer combines tabs + calendar.
```
Tab:      "planner.py — VS Code"
Calendar: "Write applyPlan() + unit tests (9–11 AM, 47 mins left)"
Observer: "Writing applyPlan() function in Python" (confidence 0.97)
```

And the Intervener message becomes:
```
Before: "You were writing Python. Twitter can wait."
After:  "applyPlan() has 47 mins left. Twitter can wait."
```
